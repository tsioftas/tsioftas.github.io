Privacy policy — Щасливої Дороги

Last updated: 5 October 2026.

The game itself collects nothing about you. The one advert in it is shown by Google, and Google does.

The advert

After a crash the game may offer a second chance in return for watching a video advertisement. It is only ever offered, never shown unasked, and turning it down costs you nothing but the run.

That advert is served by Google AdMob. To choose and show one, and to count that it was shown, Google's SDK in the game uses your device's advertising ID, your IP address, and basic information about the device and the app. How Google uses that is described at https://policies.google.com/technologies/partner-sites.

If you are in the European Economic Area, the United Kingdom or Switzerland, the game asks for your consent through Google's own form before any advert is requested, and works fully whatever you answer. You can change your answer at any time under Settings → Ad privacy in the game. You can reset or delete your advertising ID at any time in Android's settings (Settings → Privacy → Ads).

For the advert, Google's SDK asks Android for network access (INTERNET, ACCESS_NETWORK_STATE), for the advertising ID (AD_ID), for basic phone state (READ_BASIC_PHONE_STATE — such as the type of mobile network and the software version; not your calls, contacts or number), and to do its own work in the background (WAKE_LOCK, FOREGROUND_SERVICE). These are all granted at install without a prompt; the game asks for nothing else, and nothing that would show you one.

What is stored, and where

Your progress — your best run, the money you have banked, the car you drive, the finales you have collected, the settings you have chosen — is written to a file in the game's own private storage on your device. Nobody but the game can read it, and it is never sent anywhere. Uninstalling the game deletes it.

The game has no account, no sign-in, no purchases and no analytics.

Children

The game is made for a general audience and is not directed at children.

A note on how this is kept true rather than merely stated: the game's own code contains no HTTP, socket or WebSocket call — the network is used only by Google's SDK, which is confined to src/AdMob.gd and loaded on Android only. The permissions the SDK brings are pinned by a test (tests/test_adverts.gd) and by the build script, which refuses to produce a build that asks for any permission not listed in store/permissions.txt. The development telemetry that records a run to a local file only runs in a debug build — Telemetry.enabled is OS.is_debug_build(), and the copy on Google Play is not one.
